WEBSITE SURPRISE DIRA SAYANG ♡

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Buka folder surprise_dira_sayang di VS Code.
3. Klik kanan index.html lalu pilih Open with Live Server.
   Jika belum ada Live Server, install extension "Live Server" di VS Code.
4. Di website, tekan "Pilih lagu MP3" untuk memilih lagu dari laptop/HP.
5. Tekan "Tambahkan foto dari HP / laptop" untuk memilih beberapa foto.

CATATAN:
- Lagu dan foto yang dipilih dari tombol upload hanya tampil di browser/perangkat saat itu.
- Agar foto dan lagu langsung tersedia bagi semua orang saat website dibagikan, letakkan file foto dan MP3 di folder project, lalu sesuaikan HTML/JS atau gunakan hosting yang menyertakan aset tersebut.
- Browser biasanya tidak mengizinkan musik otomatis berjalan tanpa interaksi pengguna.
- Untuk membuka dari HP, hosting website online (misalnya GitHub Pages atau Netlify) adalah cara paling mudah. Jangan membagikan file musik berhak cipta tanpa izin.

FILE:
index.html = struktur website
style.css = desain dan responsif untuk HP
script.js = pemutar musik, upload foto, menu HP, dan animasi kejutan
